# The public/engine split of the kernel's public types (unit 10D; phase10-plan.md 2.1; docs/api/README.md).
# Read by tools/api-classify.cs, which writes classification.tsv and kerf-seed.map. A draft for the owner's review.
#
#   area    <Area> <public namespace, or - for none> <engine namespace>
#   package <Package> public|engine|removed <Area>[/<Sub>/<Namespace>] [pre:<Prefix>] [suf:<Suffix>]  # note
#   type    <Type> public|engine|removed <Area>[/<Sub>] [<NewName>] [=> <public replacement>]  # note
#   allow   <Name>  (a public name that is also a common .NET type's, accepted on purpose)
#
# A type rule overrides its package's. public: the type itself becomes the public type, renamed and reshaped by 10L.
# engine: it becomes internal in Kerf.Engine.<Area>, renamed by rule. removed: it goes (10J, or 10F for exceptions);
# until then it keeps its OCCT name in the namespace Occt. "=>" names what replaces it in the public API, for the
# types the modelling layer uses (docs/api/modeling-uses.txt); "new" marks a public type 10L writes.
